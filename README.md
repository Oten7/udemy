## Como usar

Os arquivos são exercícios independentes. Leia o código do exercício antes de executá-lo.

Com Python 3 instalado:

```sh
python "curso_python/curspo/sessao 3/aula.py"
```

Para JavaScript, confira se o exercício utiliza recursos do navegador ou de Node.js antes de escolher o ambiente.

Os nomes das pastas e aulas foram mantidos para preservar a referência ao curso. Este repositório registra estudos pessoais, não uma aplicação final.
